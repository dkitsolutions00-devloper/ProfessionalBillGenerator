# Professional Bill Generator

A starter Android app project designed to build an offline professional bill/invoice generator.

Features:
- Company and customer details
- Invoice number/date
- Multiple line items
- Quantity x rate
- Discount
- GST
- Grand total
- PDF generation
- Share PDF
- Offline operation

Open/import this project in Android Studio or a compatible Android IDE such as Code on the Go and build an APK.

Note: This starter version uses Android's built-in PdfDocument API and keeps data in the current session. Bill history, logo upload, persistent settings, print support, and a polished invoice template can be added in the next version.
